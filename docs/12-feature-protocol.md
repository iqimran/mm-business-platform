# Feature Development Protocol

Requirement
→ Domain Analysis
→ Database Design
→ API Contract
→ Authorization Rules
→ Backend Implementation
→ Backend Tests
→ Frontend API Integration
→ Frontend Implementation
→ Frontend Tests
→ E2E Test
→ Review

Do not skip directly from requirement to UI.

## Definition of Done
A feature is complete only when applicable:
- Database migration exists
- Model exists
- Validation exists
- Authorization exists
- API exists
- API tests exist
- Frontend integration exists
- UI validation exists
- Error states exist
- Loading states exist
- Empty states exist
- Permission restrictions work
- Branch isolation works
- Audit requirements are handled
- Relevant automated tests pass
- Documentation is updated
