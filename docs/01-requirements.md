# Requirements

## Identity
- Central user identity
- Login/logout
- Password reset/change
- Session/token management
- Authentication security

## Administration
- Application settings
- Roles
- Permissions
- User administration

## Branch
- Branch master data
- User branch access

## Car
- Cars
- Dealers
- Parties
- Expense types
- Expenses
- Sales
- Payment history
- Financial summary
- Images
- Excel imports
- Reports

## Restaurant
- Customers
- Suppliers
- Food categories
- Food menu
- Food expenses
- Offers
- Food sales
- Hall bookings

## Future Real Estate
Create only the module boundary initially. Do not prematurely design detailed functionality.

## Reporting
- Business dashboards
- Financial summaries
- Branch reports
- Exportable reports

## Audit
Audit important administrative, business, financial, and import changes.
